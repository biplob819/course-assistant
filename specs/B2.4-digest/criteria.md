# B2.4 acceptance criteria

**DIG-01** Topic labels on Luna per session from consenting learners' questions. `weekly_digest` reads the ISO week's questions from the store and sends to Luna only those whose learner has an open `improve_course` consent to the current notice version (withdrawn, never given, answer-only or unreadable consent: never sent, never counted) and whose answer is a course reply (answered, hint, or the fixed not-covered text); deleted questions are not counted; each batch is one `digest` call per session through the real `respond` with the questions inside data delimiters and no pid or id; an unreadable reply is retried once and then the run fails with nothing written.
**DIG-02** k = 5 suppression. Each row counts distinct learners, not questions; a session and topic with fewer than k learners never appears in the result or the store; a k below 5 is refused; the store refuses to write a row below k; the material-gap count is only on rows that pass and never exceeds the row count.
**DIG-03** Leak test: no topic label shares an 8-word run with a question; no pid. A label that shares a run of 5 words with any question of the week, or contains a whole question of 3-4 words, (after normalising case, accents and look-alikes) or with the rules, that holds a pid, question id, conversation id or email, or that is over 10 words or 80 characters is refused and its questions are not counted; no digest row or error message ever holds question text or a learner identifier.
