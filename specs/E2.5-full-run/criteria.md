# E2.5 acceptance criteria

The latency candidates and every function below are proved offline (fakes, scripted run
folders, synthetic ledgers). The live runs are recorded in RUN-STATE with their spend.

**FRN-01** Held-out run on Sol and Luna with dual judges; report published. The held-out split runs live through `eval_live.py` with both judges (`judge_mode = dual`) on the chosen setting and the runner-up; `fullrun.run_summary` turns each run folder into gate values, latency p50/p95 and measured cost (ledger rows of that run id plus judging spend), refusing a record without scores; `fullrun.compare` gives the paired Holm difference per gated metric; `scripts/full_run_report.py` writes `docs/measurements/e2.5-report.md` holding ids and numbers only (no case text, checked against the public questions in tests and against the held-out questions by D-54's guard where the private file exists); `release_gate.py check` runs on the held-out run and its exit code is recorded.

**FRN-02** Answer-model decision logged (quality first, then cost per grounded answer). `fullrun.choose` picks, among settings with latency p95 at most 8 s whose grounded, integrity, injection, leak and identity values are not below the reference, the one with the highest grounded rate and then the lowest cost per grounded answer, and returns no choice with the reason when none qualifies. The D-44 candidates sit behind config: `reasoning_effort` (a), `early_finalize` (b, a non-course turn finalizes without waiting for the discarded answer, which never reaches Ground, integrity, the Answer or the learner, and statuses are the same as without it for every route), `answer_model` and `hint_model` (c); (d) is recorded as not built with its reason. A decision in `docs/decisions.md` logs the choice and closes or re-scopes D-44.

**FRN-03** Measured cost model replaces §9 estimates; NFR6 checked against measurement. `fullrun.cost_model` projects a month from measured cost per question and measured run cost against the $150 cap and its $135 alarm (OWNER D-64), refusing a non-finite or negative amount; Tech Spec §9 holds the measured numbers and the NFR6 check, and §2.6 the measured latency.

**FRN-04** Read 20 sampled records end to end before trusting the headline (L-37). `fullrun.sample_for_reading` draws 20 public record ids, stratified by rule, fixed by seed, never a held-out id; RUN-STATE records what reading them found before the headline is written.
