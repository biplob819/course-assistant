# A2.5 acceptance criteria

**ASK-01** Route and answer in parallel; answer discarded unless the route is `course`. Route and answer start together on separate threads with the raw question and the window, and `ask()` waits for both; for every route but `course` the draft never reaches Ground, integrity, the Answer or the learner, its cost is still counted, and an `LLMError` from the discarded call is traced without changing the status.
**ASK-02** Finalize table (§2.2), total over every route × check combination (property test). `decide` returns exactly one status for every combination of route (six categories), ground (passed, failed, not run), integrity (passed, failed, not run), API error and leak, matching the §2.2 table: `answered` only for `course` with ground and integrity passed, no leak and no error; `error` whenever a needed call failed; and `ask()` returns a valid `Answer` for every status.
**ASK-03** Leak scan (canary, pid pattern, rules fragments). A shown model text holding A2.2's canary, a 16-hex token or a run of more than 8 words from any rules text becomes `not_covered` with the fixed text, no citations and the leak flag, for answers and grounded hints alike; the fixed texts never trigger it.
**ASK-04** Pause check and NFR8 fixed message; no silent failure. A paused scope (or a pause read failure) returns the fixed paused message with no call and nothing stored; any `LLMError` on a needed call returns status `error` with the NFR8 fixed message, stored and traced by kind only; any other exception propagates; no learner text reaches a trace.
**ASK-05** Replay injection by request id and step; golden replay fixture of 40 requests. `Replay` returns recorded results (or recorded errors) by request id, step and call number, refusing a changed request, a missing or an unused recording; the 40-request fixture built from the public split covers every status and every route and replays through `ask()` with no API calls to the stored Answers exactly, from the test suite and from `course-assistant eval-replay` in the installed wheel.
**ASK-07** Conversation window: this learner and conversation only, last 6 turns, ≤ 3,000 tokens, earlier replies without citations; 2-hour idle close; raw against rewritten retrieval measured. The window holds only this learner's turns of this conversation, at most `window_turns` whole turns within `window_tokens` (characters / 4), earlier replies as plain text with citation markers removed; a conversation idle for 2 hours, closed, or at 20 turns is closed and the turn starts a new one; recall@8 of raw against rewritten retrieval is computed by a tested function that the live smoke script runs on the public follow-up cases.
**ASK-06** 30-question smoke run: p50 and p95 latency per step, cost per question, written back to §2.6 and §9. `scripts/smoke_live.py` (live, owner-run, never in tests) runs 30 public questions through `ask()` and reports p50 and p95 latency per step and per question and cost per question, plus the public planted B7 cases (`not_covered`), the decomposition catch on the public multi-turn B3 cases and the recall@8 comparison, writing to `runs/`; the measured figures replace the planning numbers in §2.6 and §9.
