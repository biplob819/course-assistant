Append-only. Each entry: the choice, the options considered, and why. `OWNER D-n` marks an owner ruling.
D-1 to D-18 are seeded from the Tech Spec §1; D-19 to D-21 are owner rulings and D-22 a harness decision, all 15 Nov 2026 (Tech Spec §13).

| D-1 | 2026-11-15 | A request runs as a small typed graph of steps (route, retrieve and answer, check, finalize), each a pure function over pydantic models with recorded inputs and outputs | One prompt that does everything; an agent framework (Agents SDK, LangGraph) | Every rule in the behavioral spec maps to one step that can be tested on its own, and a recorded request can be replayed exactly in CI. | D-4 | 2026-11-15 | Grounding is checked in two layers at answer time.
