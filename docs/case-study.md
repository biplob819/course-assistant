# course-assistant: a grounded teaching assistant with an honest release gate

A teaching assistant that answers learner questions only from the course's own materials, cites
the slide or page, gives hints rather than solutions on graded work, and hands everything else
to the teaching team. Every release goes through an EvalKit gate scored once on a private
held-out set, and the gate is allowed to say no.

The full case study, with current results, the decisions behind them and the architecture, is
in [docs/project/project-page.md](project/project-page.md).
